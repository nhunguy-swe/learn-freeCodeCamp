Tuyển tập các bài thực hành (mini-projects) trong quá trình học chứng chỉ **Responsive Web Design** trên [freeCodeCamp](https://www.freecodecamp.org/), tập trung vào **HTML** và **CSS** cơ bản đến nâng cao (Box Model, Flexbox, Forms...).

---

## Giới thiệu (About)

Đây là repo lưu trữ và luyện tập theo lộ trình các bài học của freeCodeCamp — mỗi thư mục tương ứng với một bài tập thực hành độc lập, giúp củng cố kiến thức về cấu trúc HTML và các kỹ thuật CSS như Box Model, Flexbox, và xây dựng biểu mẫu (form).

---

## Danh sách bài tập

| Thư mục | Nội dung luyện tập |
|---|---|
| [`learn-the-CSS-Box-Model-by-Building-a-Rothko-Painting`](./learn-the-CSS-Box-Model-by-Building-a-Rothko-Painting) | Thực hành **CSS Box Model** (margin, border, padding, width/height) bằng cách tái tạo một bức tranh phong cách Rothko chỉ bằng các khối `div` và CSS |
| [`learn-CSS-Flexbox-by-Building-a-Photo-Gallery`](./learn-CSS-Flexbox-by-Building-a-Photo-Gallery) | Thực hành **CSS Flexbox** (`display: flex`, `justify-content`, `align-items`, `flex-wrap`...) để xây dựng một thư viện ảnh (photo gallery) responsive |
| [`survey-form`](./survey-form) | Thực hành xây dựng **HTML Form** hoàn chỉnh: các loại input (text, radio, checkbox, select, textarea) và validate cơ bản |

## Cách xem bài tập

Mỗi thư mục là một bài tập độc lập, chỉ cần mở file `index.html` tương ứng bằng trình duyệt:

```bash
git clone https://github.com/nhunguy-swe/learn-freeCodeCamp.git
cd learn-freeCodeCamp

# Ví dụ mở bài Photo Gallery
cd learn-CSS-Flexbox-by-Building-a-Photo-Gallery
# Mở index.html bằng trình duyệt, hoặc dùng Live Server trong VS Code
```
